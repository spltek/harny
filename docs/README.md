# Reference tools

This folder contains **reference material only**, not code executed by the extension.

`REFERENCE_TOOLS.json` lists the tools that Harny aims to implement (roadmap). The definitions
follow the well-known, widely-used agent tool set (Cursor's), used as a reference
for parameter schemas and behavior. All tools already implemented in the project live in
`src/core/tools/` with their own descriptions; this file is never read at runtime.
