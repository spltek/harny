# ── AI answer engines and assistants ─────────────────────────────────────────────
# A group named here SUPERSEDES the wildcard group for that user agent, so every group
# repeats `Allow: /` on purpose: omit it and the bot would inherit nothing at all.
#
# These groups exist to make the permission explicit and auditable — the wildcard below
# already allows them by inheritance. Naming them means a future tightening of the
# wildcard cannot silently shut an assistant out.
#
# Google-Extended is the exception in this list, and the one easiest to get wrong: it
# controls whether Google may use the page to TRAIN Gemini and ground its answers. It
# does NOT gate AI Overviews — those are built from ordinary Googlebot indexing. Turning
# it on in either direction does not change whether the page can appear in an AI Overview.
