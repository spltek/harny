Icon sheet

All of them are registered in src/chat/icons.ts and inlined at build time, so what you see here is what the panel renders. A tool call wears its own mark: toolIcon("StrReplace") → strreplace.svg, every MCP tool shares the plug, and an unknown name keeps the wrench.

One weight, one family: every tool mark is stroke-width 1.5 on the same 24×24 grid. The chrome (buttons, chevrons) keeps its own heavier weights — at 11–15 px a thinner line disappears — and where the same drawing has to serve both, the call site asks for the weight it needs (icon("trash", 13, 'stroke-width="2"')) instead of keeping a second copy of the file. skill is the only filled mark: it came in that way.
